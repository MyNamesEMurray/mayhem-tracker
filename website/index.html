What is MayhemStats?

MayhemStats shows community-powered tier lists, win rates, and ideal builds for ARAM Mayhem, the League of Legends game mode where every player drafts augments at level breakpoints. Riot's public API doesn't expose Mayhem's match data, so other sites substitute item stats from regular ARAM and augment stats from Arena — different modes with different balance. MayhemStats is built from actual Mayhem games instead: every game in the database was contributed voluntarily and anonymously by players running the free, open-source Mayhem Tracker desktop app. No scraping, no estimates, and no player identity, ever.

Scores adjust win rates for sample size so a lucky 3–0 never outranks a proven pick, tiers rank augments against their own rarity, and every champion has a build page showing its best items and augments from real community games. Read the ARAM Mayhem guide for how to read augment stats without being fooled by a small sample, see how the stats work, check the privacy policy, or install the tracker to add your own games.
