Download MayhemStats Tracker

The free, open-source desktop app that records your ARAM Mayhem matches automatically, shows you augment and item stats from your own games, and — if you opt in — contributes them anonymously to the community database behind MayhemStats.com. No account, no ads, no telemetry.

Getting started

  1. Run the download above and open MayhemStats Tracker.
  2. Leave it running and play a game of ARAM Mayhem. The app finds your League client on its own — there is nothing to configure and nothing to sign in to. Your existing Mayhem match history is imported the first time it connects.
  3. Optional: turn on Settings → Community Stats to contribute your games anonymously to MayhemStats.com. It is off until you flip it on.

Is it safe to run?

Fair question to ask of any downloaded executable, so here is everything you need to check for yourself:

  • It is open source. Every line is public at github.com/MyNamesEMurray/mayhem-tracker, MIT licensed, and the downloads above are built from that source by a public GitHub Actions workflow — not uploaded by hand.
  • Your data stays on your machine by default. Matches are stored in a local SQLite database. Nothing is uploaded until you turn on community stats.
  • Contributions carry no identity. No summoner names, Riot IDs, tag lines, or account identifiers are ever uploaded — the server's database has no columns to store them. See the privacy policy.
  • It only reads. The app talks to your own League client's local API to read finished matches. It cannot and does not modify the game, and it is not a script, overlay, or automation tool.
  • You can take it back. Settings → Community Stats → Delete my contributions removes everything your install has ever shared.

Windows SmartScreen

Windows may show a "Windows protected your PC" screen the first time you run the download. That warning is about the file's signature and reputation, not about anything it found in the file. To continue, click More info and then Run anyway. If you would rather verify first, GitHub publishes a SHA-256 digest for every file on the releases page that you can compare against your download.

Code signing

MayhemStats Tracker uses the SignPath Foundation for code signing of its Windows releases. Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: certificate pending. Releases published before the certificate is issued are unsigned, which is why SmartScreen warns on them. Once signing is live, this notice goes away and Windows will show the verified publisher instead.

Updates

The app checks for a new version at launch and periodically while it runs, and you can check on demand from Settings → General → Check for updates. Updates install in the background and the app relaunches on its own — you never have to come back to this page. Every release's changes are written up in plain language in the changelog.

Something not working?

Open an issue at github.com/MyNamesEMurray/mayhem-tracker/issues. If the app isn't picking up your games, Settings → Developer → Sync diagnostics has a copy button that captures exactly what to include.
